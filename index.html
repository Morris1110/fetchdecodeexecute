About this classroom model

RAM stores both instructions and data. The address bus carries addresses from CPU to RAM. The data bus carries instructions and data in both directions. Each of the five instructions has its own fetch, decode and execute stages.

Readable instruction names stand in for machine instructions. Input setup and output routes are simplified. The working value stands in for temporary CPU storage beyond this lesson; it is not stored inside the ALU. Other registers and control signals are omitted. Each button press covers a whole stage, containing several teaching transfers rather than literal clock counts.
